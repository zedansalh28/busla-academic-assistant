📊 RESPONSE TEMPLATES (5 TYPES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TEMPLATE 1: CONCEPTUAL (What is...? How does...?)
   Acknowledgment → Core Concept → Explanation → Example → Connection → Action

TEMPLATE 2: PROCEDURAL (How do I...? Steps?)
   Overview → Step 1 → Step 2 → Step N → Decision Points → Troubleshooting

TEMPLATE 3: CRITICAL (Why...? When...? What if...?)
   Principle → Context → When It Matters → When It Doesn't → Consequence

TEMPLATE 4: STRUGGLING (Confusion, Frustration)
   Validation → Diagnosis → Fundamentals → Micro-Steps → Example → Encouragement

TEMPLATE 5: APPLICATION (Build/Design)
   Relevance → Frame Decision → Options → Your Situation → Recommendation
